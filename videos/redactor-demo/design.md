# Redactor demo design

One typeface, one large picture, three cuts. The real tracking result carries
the demo. The user's request for simplicity takes precedence over decorative
product-launch presets.

Canvas: 1920 x 1080. Paper #f2f1e9, ink #243027. No accent, gradients, shadows,
cards, progress bars, or decorative marks.

Typography: locally bundled Syne, ExtraBold 800 for the wordmark and Medium 500
for the two comparison labels and closing line. The smallest type is 64 px.
Whole words stay still; no letter animation, typewriter effect, or rasterized
UI text. Retain the font's SIL Open Font License.

Footage: identical 1200 x 540 crops at source x=0, y=540, scaled to 1680 x 756.
Frame at x=120, y=240. Source color is unchanged. Show the original five seconds,
then replay the same five seconds from the actual SAM 2 solid-cover export.
Both run at native 1x speed. This crop keeps the tracked person visible and
removes the large signage above the street. No extra treatment is warranted.

Timing: Before 0-5 s; After 5-10 s; closing wordmark 10-12 s. Deliberate hard
cuts and silence. All on-screen copy: Redactor / Before / After /
Select. Track. Review.
